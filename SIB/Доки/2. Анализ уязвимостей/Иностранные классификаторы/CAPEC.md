Common Attack Pattern Enumerations and Classifications - список типовых паттернов проведения атак. Представляет из себя классификацию типовых атак, которые специалист по пентесту может использовать при составлении плана проведения испытаний. 

«Паттерн атаки» — это описания общих атрибутов и подходов, используемых злоумышленниками для использования известных слабых мест при атаке ИС. Паттерны атак определяют проблемы, с которыми может столкнуться противник, и способы их решения. Они вытекают из концепции шаблонов проектирования, применяемых в деструктивном, а не конструктивном контексте, и генерируются на основе глубокого анализа конкретных реальных примеров эксплойтов.

Пример использования CAPEC:

На официальной странице классификации в качестве примера используется атака типа "Использование приватных интерфейсов". 
На [сайте](https://capec.mitre.org/data/definitions/36.html) приводится следующее описание данной атаки:

- Описание
	Проведение поиска приватных интерфейсов, которые используются для внутреннего взаимодействия и не предполагаются для использования обычными пользователями. Если на интерфейсе плохо настроена авторизация, то у атакующего появляется возможности, которых изначально не было
- Расширенное описание
	Атакующий также может проводить поиск недокументированных битов на железе, которые известны как "Chicken Bits". Эти биты позволяют включать или отключать различные функции, но не публикуются. Нарушители могут провести исследование прошивки и использовать скрытые функции для вредоносного воздействия.
- Вероятность атаки
	Средняя
- Типовая серьезность
	Высокая
- Связь
	Дочерний для манипулирования интерфейсами (CAPEC-113)
- ...

	CWE-306 - отсутствие аутентификации для критичных функций  
	CWE-693 -  сбой в механизме защиты
	CWE-695 - использованию низкоуровневых возможностей
